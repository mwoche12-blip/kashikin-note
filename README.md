# 貸金業主任者 合格ノート

貸金業務取扱主任者資格試験の学習用Webアプリです。過去問（第1回〜第20回の全1,000問）を、回ごと・分野ごと・〇×一問一答・本番模試で解けます。全問に解説があり、条文をその場で確認できます。教科書と、数字を覚える暗記カードもあります。

このリポジトリは、公開用に生成したファイルだけを置いています。直接編集しないでください。

- スマホでは、ブラウザのメニューから「ホーム画面に追加」すると、アプリのように開けます。一度開けばオフラインでも使えます。
- 学習記録は、使っている人のブラウザの中だけに保存されます。外部には送信しません。

## 注意

- **日本貸金業協会その他の団体の公式アプリではありません。**
- 法令は2026年4月1日時点、監督指針は令和8年10月版によります。内容の正確性は保証しません。試験の正式な情報は、日本貸金業協会のサイトで確認してください。
